# studio-workflows (Claude Code plugin)

Teaches Claude Code to turn a project into a workflow: write `studio.yaml`, run it on your own computer with
`foundry-workflow-runner run`, or, with Foundry Studio, try it with `studio workflows dev`, deploy it with
`studio workflows deploy` and read failed runs with `studio workflows logs`.

Load it for one session with `claude --plugin-dir claude-plugin`. Check it with
`claude plugin validate claude-plugin`.
